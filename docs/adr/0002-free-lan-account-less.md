# Free LAN pairing is account-less; the cloud account exists only in the subscription tier

Zero-config, scan-to-pair LAN access is the free tier's selling point, so it stays account-less: a device pairs directly with a host using per-device credentials, with no login. The cloud account exists only in the subscription tier, where it provides identity, relay routing, push notifications, and the device registry. This trades a single identity model (one code path, but forced sign-up on the free tier) for keeping the free tier zero-config and the free/paid boundary clean.
