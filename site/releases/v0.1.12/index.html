DeepSeek Harness Desktop v0.1.12

Updates the managed DeepSeek Harness runtime to 0.1.5-rc.1, raises the Node.js floor on the 24.x line to 24.2, and stops preinstalling two plugins an earlier release added.

What changed

  • Updated the pinned upstream runtime to @deepseek-ai/dsh@0.1.5-rc.1.
  • Node.js 24.0 and 24.1 are no longer accepted. Upstream 0.1.5 runs its command-line entry point only when import.meta.main is present, and Node.js added that in 24.2, so on 24.0 and 24.1 the runtime starts and exits without ever serving the Web UI. Supported lines are now 22.19+ on the 22.x line and 24.2+ on the 24.x line.
  • Disabled the upstream ui-sidebar-documentpreview client module on WebKit versions without the Iterator global (Safari before 18.4, macOS before 15.4), where it failed to import on every launch. The rest of the right sidebar is unaffected.
  • Stopped preinstalling dsh-file-changes and @aaravarr/dsh-subagent-max; upstream 0.1.5 covers both areas itself. Upgrading removes the two plugins and the profile entries they registered, while an installation this app did not create is left untouched. The preinstalled set is now dsh-plugin-open-editor, dsh-plugin-diff-review, dsh-account-login and dsh-agent-preset-compat.
  • Launcher behaviour, trusted-LAN phone remote, account login and desktop notifications are unchanged from v0.1.11.

Known limitations

  • Phone access is for a trusted LAN, not a public internet relay. The host uses HTTPS and device pairing; do not expose it directly to the internet.
  • Node.js and npm must be installed separately.
  • Windows executables are not code-signed; macOS packages are signed with a Developer ID certificate and notarized.
  • Upstream DeepSeek Harness remains in developer preview and may introduce compatibility-breaking changes.
