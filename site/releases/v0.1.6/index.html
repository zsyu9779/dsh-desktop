DeepSeek Harness Desktop v0.1.6

Updates the managed DeepSeek Harness runtime to rc.8 and aligns startup with its supported Node.js and pnpm toolchain.

What changed

  • Updated the pinned upstream runtime to @deepseek-ai/dsh@0.1.0-rc.8.
  • Changed the launcher to bootstrap pnpm@11.7.0 through npm, matching upstream's package-manager behavior and avoiding npm peer-resolution stalls.
  • Added --no-open, explicit Node.js compatibility checks and bounded cleanup when startup times out.
  • Retained authenticated QR pairing and revocable phone access on a trusted LAN.

Compatibility

Upstream DSH@deepseek-ai/dsh@0.1.0-rc.8
Node.js22.19+ on the 22.x line, or 24+
Desktop platformsmacOS universal, Windows amd64, Linux amd64

Downloads

  • macOS universal DMG
  • macOS universal ZIP
  • Windows amd64 EXE
  • Linux amd64 tar.gz

Known limitations

  • Phone access is for a trusted LAN, not a public internet relay. The host uses HTTPS and device pairing; do not expose it directly to the internet.
  • Node.js and npm must be installed separately.
  • macOS and Windows packages are not signed.
  • DeepSeek Harness remains in developer preview and may introduce compatibility-breaking changes.
