DeepSeek Harness Desktop v0.1.4

A lightweight three-platform desktop release with improved discoverability and native macOS fullscreen behavior.

What changed

  • Improved README structure for search and AI discovery.
  • Enabled native macOS fullscreen from the green traffic-light button.
  • Retained the process cleanup and window restoration fixes introduced in v0.1.3.

Compatibility

Upstream DSH@deepseek-ai/dsh@0.1.0-rc.6
Node.js18 or later
Desktop platformsmacOS universal, Windows amd64, Linux amd64

Downloads

  • macOS universal DMG — 8.1 MB
  • macOS universal ZIP — 7.2 MB
  • Windows amd64 EXE — 9.8 MB
  • Linux amd64 tar.gz — 3.8 MB

Known limitations

  • Node.js and npx must be installed separately.
  • macOS and Windows packages are not signed.
  • DeepSeek Harness remains in developer preview and may introduce compatibility-breaking changes.
