DeepSeek Harness Desktop v0.1.5

Control the desktop Harness from a phone on the same trusted local network, paired by QR code.

What changed

  • Added authenticated LAN phone access with QR pairing and revocable credentials.
  • Improved local-network compatibility by selecting a physical network interface and adapting requests to the upstream DSH trust boundary.
  • Added remote-access documentation, screenshots and security guidance for trusted Wi-Fi use.

Compatibility

Upstream DSH@deepseek-ai/dsh@0.1.0-rc.6
Node.js18 or later
Desktop platformsmacOS universal, Windows amd64, Linux amd64

Downloads

  • macOS universal DMG — 8.9 MB
  • macOS universal ZIP — 7.9 MB
  • Windows amd64 EXE — 10.8 MB
  • Linux amd64 tar.gz — 4.2 MB

Known limitations

  • Phone access is direct HTTP on a trusted LAN, not a public internet relay. Do not enable it on untrusted Wi-Fi.
  • Node.js and npx must be installed separately.
  • macOS and Windows packages are not signed.
  • DeepSeek Harness remains in developer preview and may introduce compatibility-breaking changes.
