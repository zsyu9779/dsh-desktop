DeepSeek Harness Desktop v0.1.7

Updates the managed DeepSeek Harness runtime to 0.1.1-rc.2 and ships preinstalled plugins for diff review, subagent scaling, file changes and opening files in an editor.

What changed

  • Updated the pinned upstream runtime to @deepseek-ai/dsh@0.1.1-rc.2.
  • Upstream adds the multimodal visual understanding model DeepSeek-V4-Flash-Vision-Exp and prefers the Files API for image uploads.
  • Upstream fixes a Bubblewrap sandbox escape via /proc/<pid>/root and improves Markdown tables, cache-hit display and ask_user_question multiline input.
  • Shipped preinstalled plugins: dsh-plugin-diff-review, @aaravarr/dsh-subagent-max, dsh-file-changes and dsh-plugin-open-editor, version-tracked and upgradeable on each launch.
  • Blocked preinstalled-plugin routes over the LAN phone proxy and passed the resolved DSH_WORKSPACE to the child so workspace-bound plugin features validate against it.
  • Launcher, Node.js compatibility checks and trusted-LAN phone remote remain as in v0.1.6.

Downloads

Known limitations

  • Phone access is for a trusted LAN, not a public internet relay. The host uses HTTPS and device pairing; do not expose it directly to the internet.
  • Node.js and npm must be installed separately.
  • macOS and Windows packages are not signed.
  • DeepSeek Harness remains in developer preview and may introduce compatibility-breaking changes.
