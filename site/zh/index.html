为什么做这个项目

省掉浏览器里的启动步骤。

DeepSeek Harness 已经有完整 Web UI。本项目不重复实现 Harness，只为它补齐原生窗口和桌面生命周期。

01 / 启动

打开一个应用

检查 Node.js、拉起固定版本 DSH，等待服务就绪后自动进入界面。

02 / 本地

只监听回环地址

优先使用 3080 端口；被占用时自动选择其他本地端口。

03 / 退出

清理完整进程树

正常退出时结束 npm → pnpm → node → dsh，不留下后台服务。

明确的取舍

下载小，依赖现有运行时。

Wails 使用系统 WebView，应用也不内置 Node.js，因此安装包约 4–11 MB。相应的，使用前需要安装 Node.js 22.19+（22.x）或 24+。

如果你需要免装 Node、完全自包含的安装包，内置运行时的 Electron 版本可能更合适。

常见问题

先把限制说清楚。

DeepSeek Harness 有官方桌面版吗？

目前官方主要提供 CLI 与本地 Web UI。这个项目是非官方社区桌面壳，与 DeepSeek AI 无隶属关系。

为什么必须安装 Node.js？

桌面壳通过 npm 与 pnpm 启动固定版本的官方 DSH npm 包。没有内置 Node.js，才换来了约 4–11 MB 的安装包。

数据和 API Key 在哪里？

会话、模型凭证和插件数据由上游 Harness 管理；桌面壳自己的启动日志位于 ~/.dsh-desktop/logs/。

为什么系统提示未知开发者？

v0.1.6 还没有 macOS notarization 或 Windows 商业代码签名。请只从本项目 GitHub Releases 下载，并根据自己的信任要求决定是否运行。

首次启动为什么慢？

第一次需要通过 npm 与 pnpm 下载 DSH 及依赖。缓存完成后，后续启动通常更快。
